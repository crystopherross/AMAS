# Outputs
This folder contains all output files created by the tool, the contents of this folder are not tracked by GitHub (see `.gitignore`). The current version of the tool can produce two types of files: `.txt` and `.trace` files, the `.txt` files are those that describe some structure (AMAS, I/O iCGS, Projection) that has already been constructed by the tool. The `.trace` files detail the algorithmic trace of the construction of some structure, more specifically an I/O iCGS, a MKBSC projection, or a MKBSC expansion. The `.txt` files are created by using the `.print()` methods for the corresponding classes, while the `.trace` files are created by specifying the optional parameter `trace_file` of the corresponding constructors.
